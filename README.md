# 欢迎来到小林的世界

一场以「入梦小说」为主题的个人静态主页，参考蜡笔文具店的互动结构重新编织：书页翻动开场、关键词拾取、人物设定收纳、个人须知、双柜相册、本地留言板，以及结尾的一张梦境船票。支持白日 / 黑夜两种光线。

## 目录结构

```
xiaolin-world/
├── index.html        # 页面本体（样式与脚本全部内联，单文件自包含）
├── assets/           # 页面配图（封面、影像、伴手礼）
└── README.md
```

## 本地预览

直接用浏览器打开 `index.html` 即可；留言与主题偏好保存在浏览器本地（localStorage），无需服务器。

## 发布到 GitHub Pages

1. 在 GitHub 新建一个仓库（例如 `xiaolin-world`，公开或私有均可）。
2. 在本目录初始化并推送：

```bash
git init
git add .
git commit -m "欢迎来到小林的世界：梦境小说主题主页"
git branch -M main
git remote add origin https://github.com/<你的用户名>/xiaolin-world.git
git push -u origin main
```

3. 仓库页面依次进入 **Settings → Pages**，Source 选择 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`，保存。
4. 等待一两分钟，访问：

```
https://<你的用户名>.github.io/xiaolin-world/
```

## 内容说明

- **关键词**：晚潮、旧信、雾港、星屑、白帆、长夜，可多选，选中项会印到结尾船票上。
- **人物设定**：对应原「购物环节」，展示作者落笔时为角色添入的特质，可收入行囊并同步到船票。
- **相册**：分「影像」「伴手礼」两柜，仅展示画面，不配文案；点击可放大。
- **留言板**：支持文字与本地上传图片，数据仅存于当前浏览器；页面已提示截图发给梦境主人，否则关闭后会消散。
- **船票**：结尾印入梦关键词与人物设定，附编号与一句结语。
- **昼夜模式**：右上角按钮切换，选择会被本地记住。
